==========================================================
  BUDGET APP — HOW IT'S HOSTED (Convex backend + GitHub Pages)
==========================================================

The app has two halves:

  FRONTEND  index.html  ......  hosted free on GitHub Pages
                                https://eloren18.github.io/budget/
  BACKEND   convex/ folder ...  hosted free on Convex (database + sign-in)
                                dashboard: https://dashboard.convex.dev
                                project "claude-budget-app", team "kerem-ekdal"
                                production URL: https://enduring-hare-88.convex.cloud

Your budget is stored in Convex, tied to your email, and syncs live across
every device you sign in on. Sign-in = your email + a 6-digit code emailed
to you. Codes are sent through Resend (https://resend.com) — the free plan
delivers only to the email the Resend account was created with
(keremladkeholland@gmail.com), which is also the app's admin email. That's
fine for one person; to let other people sign in you'd add a custom domain
in Resend, then add their emails under ⚙ Settings → Manage access.

Backups: ⚙ Settings → Backup → "Export data" downloads your whole budget as
a JSON file; "Import data…" restores one. Do an export now and then.


----------------------------------------------------------
UPDATING THE APP
----------------------------------------------------------
- Frontend change (index.html): run Deploy.bat (commits + pushes; GitHub
  Actions republishes the site within a minute).
- Backend change (anything in convex/): in this folder run
      npx convex deploy -y
  (or double-click Deploy-Backend.bat). The frontend and backend are
  independent — deploy whichever you changed. The browser client version
  pinned in index.html (convex@1.44.0) should match package.json.
- Local testing against the DEV deployment: `npx convex dev` pushes to
  dev (little-ibis-573); the page can be pointed at another backend via
  localStorage key "budgetConvexUrl" (never needed in normal use).


----------------------------------------------------------
ONE-TIME SETUP (already done — for reference / a new machine)
----------------------------------------------------------
1. Convex account at convex.dev; in this folder: `npx convex dev --once`
   (logs in, creates/links the project, writes .env.local — git-ignored).
2. Resend account (signed up with the admin email) → API key →
      npx convex env set RESEND_API_KEY re_xxx
      npx convex env set --prod RESEND_API_KEY re_xxx
3. `npx convex deploy -y` to push the backend to production.
4. GitHub Pages: repo → Settings → Pages → Source "GitHub Actions"
   (.github/workflows/deploy.yml publishes index.html on every push).


----------------------------------------------------------
SECURITY NOTES
----------------------------------------------------------
- Only the admin email, or emails on the access list, can request a
  sign-in code (enforced on the server). Codes are hashed, expire after
  10 minutes, allow 5 wrong tries, 30s between sends, 15 sends/day.
- Sessions last ~6 months per device; removing someone from the access
  list signs them out everywhere immediately.
- The admin email is set in TWO places: index.html (ADMIN_EMAIL) and
  convex/lib.ts (ADMIN_EMAIL). Change both if it ever changes, then
  deploy both halves.


----------------------------------------------------------
TROUBLESHOOTING
----------------------------------------------------------
- Code email not arriving: check spam; make sure you typed the admin
  email; Resend free plan only delivers to that address.
- "A code was just sent": wait 30 seconds and try again.
- Header shows a red sync dot: the browser can't reach Convex (offline, or
  a network blocking *.convex.cloud). Your edits are kept on the device
  and pushed when the connection is back.
- See what's stored: dashboard.convex.dev → claude-budget-app → Data.
